# 三角猫行动 · Operation Tri-Cat

原创猫咪主题的单人搜打撤浏览器游戏。整备、探索、射击、搜索、撤离，再把战利品带回暖窝。

在线游戏：**https://biscuit19.github.io/CodexGame2/**

## 游玩

推荐桌面 Chrome / Edge / Firefox，键盘与鼠标。首屏有操作手册；初始已配备武器、护具、背包和补给，可以直接开始行动。

| 按键 | 操作 |
|---|---|
| WASD / Shift | 移动 / 奔跑 |
| 鼠标 / 左键 | 瞄准 / 射击 |
| Space / R | 翻滚 / 换弹 |
| E / F | 搜索交互 / 吃食物 |
| Tab / M | 背包 / 战区地图 |
| 1、2 / 滚轮 | 切换主副武器 |
| Esc | 关闭窗口 / 暂停 |

靠近容器按 E。物品按价值逐件揭示，点击拾取，Shift 点击放进安全箱。免费撤离点留在圈内连续五秒即可，付费点需要先按 E 支付。每局十五分钟，剩余五分钟警告。出击中的背包、保险箱和地图界面不暂停战斗；Esc 暂停。

## 内容

- 四张有不同环境、掩体、开口与敌人组合的地图。
- 六名主线 Boss，以及断尾高架的可选精英首领；最终关三名 Boss 分阶段攻略。
- 十二把武器、五级护甲与头盔、五种背包、四级子弹、四种食物。
- 六十件带幽默说明的原创猫化收藏品，五档品质与分级揭示音效。
- 商店、死亡回购、一键整备、65% 回收、护具修复与耐久损耗。
- 60/80/120/200/450 格仓库和 1/2/4/6 格安全箱。
- 两种死亡模式，跨局 Boss 进度、最终密钥门槛、主线结局与九命周目。
- 三个独立本地存档槽、IndexedDB 与本地备份、导入导出、刷新中断结算。
- 自绘伪 3D 场景、骨骼式猫咪动画、原创 SVG 图标与合成配乐/音效；无运行时外部素材依赖。
- 首次在线加载完成后，Service Worker 缓存允许离线再次游玩。

普通敌人具有视线遮挡、听觉调查、寻路、换弹、侧移和品种对应行为。Boss 分别使用散射、闪避、增援、冲撞、护盾与炮塔。敌人掉落实际武器及剩余耐久的护具。

## 本地开发

Node.js 22 或更高版本：

```sh
npm ci
npm run dev
```

```sh
npm test                 # 数据、经济、存档、战斗与地图可达性测试
npm run test:e2e         # Chromium 浏览器流程
npm run build           # 类型检查、生产构建、离线缓存
npm run preview         # 验证生产构建
```

本机 E2E 默认使用 `/usr/bin/chromium`；可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`。CI 使用 Playwright 安装的浏览器。浏览器测试的测试接口仅在 Vite 开发模式且 URL 有 `?test=1` 时存在；生产构建不提供测试入口。

## 发布

推送 `main` 后，GitHub Actions 自动执行系统与浏览器测试，再构建并部署 GitHub Pages。Pages 使用 GitHub Actions 作为构建来源。所有资源使用相对路径，支持仓库子路径部署。

## 结构

- `src/data.ts`：内容配置、掉落与数值计算。
- `src/store.ts`：物品事务、经济、存档与结算。
- `src/raid.ts`：局内模拟、AI、战斗、搜索、Boss 与撤离。
- `src/art.ts` / `src/render.ts`：原创图标、角色、场景与渲染。
- `src/audio.ts`：Web Audio 合成配乐与效果。
- `src/main.ts` / `src/style.css`：Phaser 帧循环、输入与界面。

设计基线见 [GAME_DESIGN.md](GAME_DESIGN.md)，用户提供的表现理念保存在 [docs/ART_DIRECTION.md](docs/ART_DIRECTION.md)。

四小时通关是平衡设计目标，尚不代表经过完整四小时人类盲玩统计。首版采用程序绘制的卡通 2.5D 美术和骨骼式动画，后续可以替换为更精细的预渲染素材。进度保存在当前设备的浏览器内，不同设备不自动同步。
