# 三角猫行动 · Operation Tri-Cat

原创猫咪主题的单人搜打撤浏览器游戏。整备、探索、射击、搜索、撤离，再把战利品带回暖窝。

在线游戏：**https://biscuit19.github.io/CodexGame2/**

## 游玩

推荐桌面 Chrome / Edge / Firefox，键盘与鼠标，开启硬件加速。首页提供新的游戏、继续游戏、设置；新存档默认标准模式，也可选择轻松模式。初始已配备武器、护具、背包和补给。

| 按键 | 操作 |
|---|---|
| WASD | 默认疾跑，持刀时更快 |
| 鼠标 / 左键 | 瞄准 / 射击 |
| Space / R | 翻滚 / 换弹 |
| E / F | 搜索交互 / 吃食物 |
| Tab / M | 背包 / 战区地图 |
| 1、2、3 / 滚轮 | 主副武器与近战；滚轮可双向循环，跳过空位 |
| 3 | 切换猫爪短刀，左键近战挥击 |
| Esc | 先关闭背包／搜索／地图；无窗口时打开游戏菜单 |

靠近容器按一次 E，同时显示左侧背包与右侧容器。物品按价值逐件揭示，双击拾取；更强的头盔或护甲会直接替换，旧装备留在容器中。防护评分按等级×剩余耐久比较。容器食物可以直接食用，不占背包。在局内把背包物品拖到场景上即可丢弃，落地后可以重新拾取。

搜索期间再次按 E 同时关闭背包与容器。方向键默认疾跑，Shift 不再切换；持枪移速 220，持刀 270。体力上限 100，持续跑动约 30 秒耗尽，翻滚消耗 10。耗尽后疲劳减速；只要不疾跑立即恢复体力，达到25后自动恢复疾跑。

装备栏位于背包最上方，包含主副武器、护甲、头盔、背包、子弹、近战和食物。支持拖拽替换；空装备位时，仓库物品双击优先穿戴。背包为 20／30／40／55／75 格，每行五格。子弹每格最多 120 发，同等级自动合并；装备备弹自动从背包补满。将弹药拖到主副武器可直接装填并同步切换备弹，换品质时旧弹匣退回背包，空间不足则取消整笔操作。补给每格最多5份，同种自动合并，食用只扣一份。武器保留已装填的弹匣，撤离不卸弹，也不生成待整理战利品。旧存档会迁移已有子弹和溢出物资。

所有物品保留原描述，点击在旁边显示描述和竖排选项，也可悬停查看。背包和仓库使用正方形格子并显示空位；筛选隐藏的物品标为占用，不虚增空位。成功撤离保留背包，由玩家自行整理到仓库；轻松模式死亡仍按原规则归还仓库。

仓库背包旁有「全部放回」按钮，空间不足时仅留下放不下的物品。背包物品可直接出售；装备、子弹和补给的出售价值只在点击后的物品描述中显示。枪械按品质拥有 100／125／150／185／220 耐久，新枪实际射出 700 发耗尽，低于 30 耐久逐渐降低伤害，最低保留 30% 威力。基地可修复枪械及护具，修复会损耗最大耐久，旧存档自动迁移。

Esc 菜单和基地设置菜单使用浏览器原生顶层对话框，避免游戏画布遮挡；声音设备异常不影响按钮响应。基地设置按钮打开包含「返回开始界面／设置／操作指南／继续整备」的菜单。浏览器回归测试会把游戏画布提升到最高层级，检查菜单的实际点击命中并保存截图；生产部署后再次验证。

菜单本体负责背景和居中布局，不使用嵌套固定遮罩及背景模糊，减少 Chrome 的合成兼容问题；原生模态失败时也会显示菜单。CI 同时使用 Chromium 和 Google Chrome 检查菜单。搜索开始时清除接近容器时尚未松开的方向键输入，避免搜索一打开就被上次移动打断。

免费撤离点留在圈内连续三秒即可，付费点需要先按 E 支付。每局十五分钟，剩余五分钟警告。背包、保险箱和地图界面不暂停战斗。Esc 先关闭背包、搜索或地图；没有窗口时打开居中游戏菜单，提供继续、设置、指南和退出本局。切换页面或窗口失焦也会打开此菜单并停止局内模拟。退出恢复出击前的物品、金币、弹药、耐久与进度，不带出本局收集品；主动修改的声音设置保留。刷新中断仍按原死亡规则结算。

## 内容

- 四张有不同环境、掩体、开口与敌人组合的地图。
- 六名主线 Boss，以及断尾高架的可选精英首领；最终关三名 Boss 分阶段攻略。
- 二十把武器：5把冲锋枪、8把步枪、3把狙击枪、4把霰弹枪；五级护甲与头盔、五种背包、四级子弹、十种补给。
- 枪械、护具、背包、短刀、弹药和补给共50件使用彩色PNG图标。20款枪械在地图一具有对应配色与猫化特征的独立手持模型。商店支持按四类枪械筛选；详细数值见 [枪械配置](docs/WEAPONS.md)。
- 霰弹一次发射7～8枚弹丸，只消耗1发备弹与一次耐久；近距离爆发高，越远散布和伤害衰减越明显。敌人同样使用实际枪械的弹丸数、射程与换弹时间，掉落对应武器和剩余耐久。
- 七十件带幽默说明的原创猫化收藏品，五档品质与分级揭示音效。
- 商店、死亡回购、65% 回收、护具修复与耐久损耗。
- 60/80/120/200/450 格仓库和 1/2/4/6 格安全箱。
- 两种死亡模式，跨局 Boss 进度、最终密钥门槛、主线结局与九命周目。
- 三个独立本地存档槽、IndexedDB 与本地备份、导入导出、刷新中断结算。
- 地图一「猫尾乡野」按乡村、农田、宽河与三座桥重建，地图扩展至13000×10000，六栋完整圆润乡村建筑采用经过 Blender 修改的 Tiny Treats CC0 模型，拥有宽敞室内、多方向门洞和局部小地图；授权与来源随仓库保留，详见 [地图说明](docs/MAP1_COUNTRYSIDE.md)。
- 地图一采用 Three.js 正交立体场景，真实几何猫咪、灯光、遮挡与关节动画，行走时身体扭动、双腿交替、尾巴摆动。地图二至四沿用已有画面和关卡内容，本轮未重做。
- 全中文大字界面、五块基地入口、原创图标与合成配乐/音效；无运行时外部素材依赖。
- 首次在线加载完成后，Service Worker 缓存允许离线再次游玩。

普通敌人具有视线遮挡、听觉调查、寻路、换弹、侧移和品种对应行为。发现玩家时会通知同房间或附近视线相通的同伴协同追击。所有敌猫的名字常驻显示在头顶。Boss 分别使用散射、闪避、增援、冲撞、护盾与炮塔。敌人掉落实际武器及剩余耐久的护具。

## 本地开发

Node.js 22 或更高版本：

```sh
npm ci
npm run dev
```

```sh
npm test                 # 数据、经济、存档、战斗与地图可达性测试
npm run test:e2e         # Chromium 浏览器流程
npm run build           # 类型检查、生产构建、离线缓存
npm run preview         # 验证生产构建
```

本机 E2E 默认使用 `/usr/bin/chromium`；可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`。CI 使用 Playwright 安装的浏览器。浏览器测试的测试接口仅在 Vite 开发模式且 URL 有 `?test=1` 时存在；生产构建不提供测试入口。

## 发布

推送 `main` 的游戏或发布配置改动后，GitHub Actions 执行类型检查与构建，将产物发布到 `gh-pages` 分支，并轻量检查公开站点版本和入口资源。相关功能测试在开发时按改动范围选择，不在每次发布时重复全量执行。纯文档修改不触发游戏发布。Actions 手动运行可选择相关单元测试、浏览器用例或完整回归，详见 [测试策略与完整清单](docs/TESTING.md)。Pages 使用 `gh-pages` 分支根目录作为来源。所有资源使用相对路径，支持仓库子路径部署。

## 结构

- `src/data.ts`：内容配置、掉落与数值计算。
- `src/store.ts`：物品事务、经济、存档与结算。
- `src/raid.ts`：局内模拟、AI、战斗、搜索、Boss 与撤离。
- `src/art.ts` / `src/render.ts`：原创图标与原有地图渲染。
- `src/village.ts` / `src/village-ground.ts` / `src/village-scene.ts`：地图一布局、地形、公开模型加载及遮挡。
- `src/three-render.ts`：地图一的立体场景、猫咪模型、动画和正交瞄准投影。
- `src/audio.ts`：Web Audio 合成配乐与效果。
- `src/main.ts` / `src/app.ts` / `src/app.css`：启动、帧循环、输入与界面。

设计基线见 [GAME_DESIGN.md](GAME_DESIGN.md)，用户提供的表现理念保存在 [docs/ART_DIRECTION.md](docs/ART_DIRECTION.md)。

四小时通关是平衡设计目标，尚不代表经过完整四小时人类盲玩统计。地图一需要支持 WebGL 的桌面浏览器。进度保存在当前设备的浏览器内，不同设备不自动同步。

收集品更新：70 件收藏品（常见8／优良9／珍贵25／稀世16／传说12），15 件新图标与统一问号图标。五件食品改为补给，全部9种补给提供即时、持续、混合恢复，恢复量整体降低。搜索揭示就登记发现，无须拾取；未发现图鉴仅显示名字与问号，隐藏价值。移除原生 title，保留自定义悬浮说明。完整内容与恢复数值见 [收集品和补给文档](docs/COLLECTIBLES.md)。

新版界面：图鉴详情使用Chrome兼容的原生顶层弹窗，未发现项只显示描边问号；收集品名字按白、绿、蓝、金、红区分五档品质。仅收藏品触发顶部中央解锁发现，五档停留1／1.5／4／5.5／7秒，珍贵以上在下方展示大字原描述，第一行显示小字四字提示、解锁、大号彩色名字与物品图标，不再弹右下角重复提示。图鉴已发现物品支持悬浮查看描述。武器HUD为紧凑横向双栏：左枪名、无独立背景的大枪图和耐久，右弹药数字、小弹药图与弹种。撤离结算使用Chrome顶层弹窗；商店补给按价格、武器按品质升序排列。

开发测试入口位于开始页右下角的极淡小点，悬停可显现。点击直接进入临时基地，拥有999999金币、70件已解锁图鉴和全部地图。它不占用或覆盖正式存档，退出或刷新即可结束。浏览器开发规范见 [AGENTS.md](AGENTS.md)，以后按改动范围执行相关测试；完整清单保留供按需回归。

撤离结算只统计本局新获得且最终带回的物资，原有装备、背包和安全箱内物品均不计入；弹药和补给合并后仍能区分来源。基地仓库、商店、地图、图鉴页面按 Esc 返回基地，若有详情弹窗则先关闭弹窗。

当前食物有独立装备栏：出击自动装备最低品质食物整堆，F食用，吃完自动续装；战斗生命体力框右侧显示食物图标、名字和份数。安全箱格子与背包等大，标题和容量亮金色；六格可横向滚动。收藏中饮食造型已换为日用品和奇幻道具，快乐餐盒移至补给，收藏仍70件、补给增为10种。16件新图标使用透明PNG，回血量已整体提升，持续回血总量高于同级即时回血。稀世提示「金色传说！」，传说提示「天降横财！」；更稀有发现覆盖后不会重播被覆盖提示。
