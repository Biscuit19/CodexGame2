# 彩色装备图标

两张透明 PNG 图集由图像生成工具绘制，风格基于确认后的三尾47样图：简洁彩色色块、深色描边、夸张猫化特征。游戏运行时不依赖外部图片服务。物品栏、商店和搜索界面共用图集，收集品图标沿用原方案。

- `weapons.png`：4列×5行，顺序为 `w0` 至 `w19`，对应 `src/data.ts` 的20款枪。
- `equipment.png`：4列×6行，依次为 `a1…a5`、`h1…h5`、`b1…b5`、`k0`、`m1…m4`、`f1…f4`。
- `src/equipment-art.ts` 维护图集坐标、界面与平面场景的绘制入口，以及手持模型使用的对应配色。
- 地图一的枪械是独立立体模型，按枪型和名称特征生成几何结构，并在切换装备时更新。地图二至四以同一PNG图标绘制手持武器。

`src/icon-frames.ts` 记录从原始 PNG 的透明区域测量出的每件图标边界，移除相邻单元溢出碎片。界面以 CSS 取图并保持物体比例，平面场景使用同一坐标绘制；原始图片保持不变，不需要运行时生成图片文件或下载字体。
