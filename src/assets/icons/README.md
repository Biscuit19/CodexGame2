# 彩色装备图标

六张透明 PNG 图集由图像生成工具绘制，风格基于确认后的三尾47样图：简洁彩色色块、深色描边、夸张猫化特征。游戏运行时不依赖外部图片服务。物品栏、商店和搜索界面共用图集，70 件收集品也使用相同风格的独立彩色图标。

- `weapons.png`：4列×5行，顺序为 `w0` 至 `w19`，对应 `src/data.ts` 的20款枪。
- `equipment.png`：4列×6行，依次为 `a1…a5`、`h1…h5`、`b1…b5`、`k0`、`m1…m4`、`f1…f4`。
- `src/equipment-art.ts` 维护图集坐标、界面与平面场景的绘制入口，以及手持模型使用的对应配色。
- 地图一的枪械是独立立体模型，按枪型和名称特征生成几何结构，并在切换装备时更新。地图二至四以同一PNG图标绘制手持武器。

`src/icon-frames.ts` 记录从原始 PNG 的透明区域测量出的每件图标边界，移除相邻单元溢出碎片。界面以 CSS 取图并保持物体比例，平面场景使用同一坐标绘制；原始图片保持不变，不需要运行时生成图片文件或下载字体。

- `collectibles-0.png`、`collectibles-1.png`、`collectibles-2.png`：各 4 列×5 行，总计 60 个历史物品图标（其中5件现为补给），按 `c0_0…c0_11,c1_0…c4_11` 连续排列，每图 20 件。稳定编号与名称见 `src/collectibles.ts`。
- `src/collectible-frames.ts`：原图透明像素测得的独立边界，按物品编号映射，图片原件不改动。图鉴、背包、仓库与容器共用这些 PNG，图鉴未发现图标仅用 CSS 降低饱和度。

- `collectibles-3.png`：4列×4行，依次为 `c5_0…c5_14` 的15件新增收藏，最后一格为未发现图鉴使用的统一问号。对应边界在 `src/extra-collectible-frames.ts`。
- 五件转为补给的旧编号仍从原收藏图集取图；旧三张图集不修改，不会丢失存档物品或图标。
