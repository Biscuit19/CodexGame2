# 搜索背包与战斗平衡调整（2026-10-27）

## 背包与装备栏

- 搜索逐件揭示、拾取及其他战区面板刷新前记录左侧 `.inventory-scroll.scrollTop`，重建后立即恢复；不改变容器揭示进度。
- 战区背包标题、已用/总格数、本局收入、整理放在一行，压缩装备图标、标题和耐久字高，为背包保留更多高度。
- 装备中的子弹栏显示当前弹种的装备栏数量 + 背包同弹种数量，不显示弹匣和“备弹”。其他弹种不计入。
- `beginRaid` 在备份原始整备后，若背包栏为空，免费穿戴 `b1` 布兜（当前20格）；已有背包保持原样，取消出击按原备份恢复，避免复制。

## 伤害与血量

- 20款枪械基础伤害统一按原数值的80%取整，直接修改物品属性，面板与调整台同步；近战基础伤害不变。
- 四级弹药伤害系数由 `0.9 / 1 / 1.12 / 1.28` 改为 `0.75 / 0.88 / 1 / 1.15`；穿透等级不变。
- 爆头倍率 `1.5 → 1.2`，即降低20%。
- 普通敌猫基础生命由 `55 + 装备级别×17` 改为 `70 + 装备级别×22`，所有地图采用；周目生命加成保留。
- 地图一额外按资源区增加生命：诊所×1.15、谷仓×1.4、Boss护卫×1.65；其他普通区域×1。
- 地图一铁腮Boss基础生命 `650 → 850`。敌人数量、护甲等级与其他地图Boss生命不改。
- 例：满状态卷尾猫兹14基础伤害，一级弹打二级完整护甲的铁腮，近距身体单发约2.94；四级弹约13.69，体现弹药穿透差距。护甲被打坏后伤害会增加，不能把这个数值当成整场固定伤害。

## 头部命中

- 取消单独使用 `子弹y < 敌人y-34` 的判定。
- 玩家与敌人共用投影坐标下的椭圆头部区域，并检查入射方向的短距离弹道，允许从左右脸边缘进入头部；腹部、脚部及朝外飞走的子弹不因此算爆头。
- 头部区域也参与飞弹碰撞，避免看似命中头顶却未触发碰撞。
- 近战保留身体伤害，不套用新增的子弹爆头检测。
