## 播放与选择

初始音量100%，原声和候选均按需加载，未加入普通游戏离线预缓存。换弹/搜索单选；两类猫叫可多选并复制完整清单。提供同类10条连听、停止、展开完整原声、换弹同步、搜索6/12秒循环、选择同风格前五条和随机连听。随机从已选（未选时用前五条）无重复抽最多五条；不足五条只播放实际已选，不伪装成五种。

搜索只保留一个短材料动作与停顿，以普通试听30%幅度（约-10.5dB）播放；受击猫叫50%（约-6dB），警戒65%（约-3.7dB）。原声参考播放器也沿用对应低音量基准。原声转FLAC只做必要防削波固定增益；候选固定音量、剪切、4毫秒剪切边缘防咔哒，无变调、EQ、合成或多层新设计。换弹的播放器同步只改变播放速度，不修改下载原音。

## 检索与比较

本轮先用Brave查询开发者推荐、换弹和猫叫用途，正常访问itch.io、SoundBible、Wikimedia Commons、BigSoundBank、公开游戏官网和原作者资源，再以原页核对许可。不是只在GitHub挑包；GitHub在这里主要用于固定开放游戏原件和具体授权。公开游戏原音同样不等于“可以随便提取”，逐项检查音频资源的授权而不是只看代码许可。

Brave多个查询正常返回后出现429，停止继续请求；DuckDuckGo给出验证页未继续。itch某些多标签列表403，使用可正常访问的原作者页面；不绕过验证。Wikimedia第一次请求要求设置User-Agent，按其说明提供真实项目研究标识后正常返回官方元数据，没有冒用浏览器身份。

## 复现与测试

`scripts/assets/reload-search-cats-sources.json`，固定40个原件哈希、来源和剪切/固定增益配方；成品及原声哈希也在公开manifest。按recipe的source.path整理原始文件到缓存后：

```sh
python scripts/assets/build-action-audio-review.py --cache /tmp/audio-next-research --recipe scripts/assets/reload-search-cats-sources.json --out public/audio-review/reload-search-cats
```

作者许可全文、独立许可说明与Xonotic对应原OGG随页保留。不得擅自把FilmCow和Chequered Ink写成CC0。通用构建器默认仍要求五候选，本轮recipe明确candidateCount=10，不改上轮页面。

Chrome专项检查80个原件/成品哈希和真实解码、四组各10个不同源、默认满音量、搜索循环停止、猫叫多选/随机停止/复制、手机布局；只运行相关用例。游戏接入验证见采用记录。构建检查三批未选试听素材均不进入普通游戏缓存。部署后仅做版本、新页和代表资源检查，不重复全量游戏流程。
