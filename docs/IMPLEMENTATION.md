# 实现与验收说明

本次实现遵循 `GAME_DESIGN.md` 0.3 版及 `ART_DIRECTION.md`。以下记录具体技术选择和验收边界，避免把设计目标当成实测结论。

## 技术选择

采用 TypeScript、Phaser 3 和 Vite。Phaser 提供稳定帧循环、窗口缩放及 Canvas 渲染宿主；独立 Canvas 2D 绘制器完成 Y 排序、立体掩体、角色骨骼动画、粒子与遮挡半透明。地图由数据配置和有种子随机物资生成，没有运行时 Tiled 或外部贴图依赖。

图标为按物品语义绘制的透明 SVG。地图与猫咪的外观统一使用低饱和绿、暖金与木色，战区分别体现工厂、高架、港口和雪地实验室。配乐与反馈声音全部通过 Web Audio 原创合成，音量可分别调节。

## 进度规则

主线首领顺序：铁腮、闪尾、猫伊德，然后最终地图的零号缅因与霜瞳（顺序自由），最后博士。前两把权限密钥必须成功撤离后才永久保存；博士不会在密钥不足时生成。博士击败后同样需要撤离成功才通关。Boss 信物为任务进度，不占库存格。

死亡和中断遵守当前模式。轻松模式完整保留物品，标准模式保留安全箱与原仓库；所有出战弹匣记录在存档中，中断恢复会返还或丢失对应子弹。结算以 pending 标志保证只执行一次。仓库容量溢出进入待整理区，处理完成前不能再次出击。

## 自动验证

系统测试涵盖一万道保险箱题的合法性、穿甲与伤害、弹药堆叠事务、装备交换、购买门槛、升级、护具修复、死亡结算、幂等结算、中断恢复、备份恢复、真实弹道、十二把武器、换弹与翻滚结束状态、进食打断、付费撤离、四地图可达性及最终密钥门槛。

浏览器测试覆盖完整新手到撤离循环、真实键鼠射击、暂停、仓库双击装备、购买、安全箱、存档槽、导出、最终关跨局进度、结局与新周目。其中最终关流程测试直接准备首领击败状态，以验证结算和界面；它不是完整人类实战通关记录。

生产构建另验证子路径加载、没有开发测试接口、离线缓存可用及无未处理的脚本错误。

## 仍需长期观察的目标

约四小时首轮通关时间、武器长期平衡、不同硬件下 60 FPS 和广泛浏览器兼容性是持续验证目标。自动化流程与 Chromium 实际运行通过，不能替代大样本人类试玩。
