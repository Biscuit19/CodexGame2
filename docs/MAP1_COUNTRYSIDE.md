# 地图一：猫尾乡野

本轮仅重建地图一。地图二至四、玩家猫咪、装备、物品、搜索速度、15分钟局时、死亡模式及3秒撤离规则沿用现有实现。

## 布局与通路

平面尺寸2400×1800，左上为(0,0)，右为东，下为南。保留大量空地，仅18棵树、8处岩石与少量箱堆作区域提示和掩体。道路和地面由配置绘制，未使用参考图片作地面。

宽150的河流从西北进入，经猎人和中央之间，转向下半部向东流出。另一段西支流隔开出生岸与猎人区域。水面实际阻挡移动；桥面按角色半径留出通行范围。视线和子弹仍可跨水，AI移动则必须绕桥。

三条路线都不强制击杀Boss：

- 安全路线：出生 → 猎人小屋 → 连接桥 → 中央 → A。
- 搜索路线：出生 → 主木桥 → 杂货铺 → 诊所 → 谷仓 → A。
- 高风险路线：中央 → 谷仓 → 农庄 → B（若本局关闭，可退向A或付费点）。

## 容器与资源梯度

| 区域 | 固定容器 | 概率容器 |
|---|---|---|
| 出生 | 纸箱1、猫砂桶1 | 无 |
| 猎人 | 纸箱2、猫砂桶1、工具柜2 | 武器箱50% |
| 中央野外 | 纸箱4、猫砂桶1 | 工具柜40% |
| 诊所 | 医疗箱3、纸箱1、工具柜1 | 豪华猫窝25% |
| 商店 | 纸箱3、猫砂桶2、工具柜1 | 豪华猫窝20% |
| 民居 | 纸箱2、猫砂桶1 | 工具柜20% |
| 农田 | 纸箱3、猫砂桶2 | 工具柜40% |
| 谷仓 | 工具柜2、武器箱1、纸箱2、豪华猫窝1 | 第二武器箱60%、保险箱35% |
| 农庄 | 武器箱2、工具柜2、豪华猫窝1、保险箱1、纸箱1 | 第二豪华猫窝50% |

每个普通容器2件物品，高价值容器3件。容器外形区分纸箱、猫砂桶、抽屉工具柜、医疗箱、长武器箱、软猫窝和带转轮保险箱。

收藏品质权重按区域逐级提高。出生只产常见收藏；野外没有稀世/传说；农田、商店、猎人与诊所可极少出现稀世。传说仅在谷仓（每次收藏抽取0.01%）与农庄（0.1%）出现。此概率不等于每箱概率，因为容器也会抽到装备、弹药和补给。

诊所只抽补给与收藏，不抽枪械、弹药、护甲。猎人更常出现低级弹药，概率武器箱提供1～2级武器。谷仓可出1～3级武器/弹药，农庄可出1～4级武器、2～4级弹药与较高护甲。所有最终搜索位置都经过碰撞校正，容器不会放到水中或墙内。

## 敌人与导航

- 固定19只普通敌猫：猎人2、诊所2、商店2、民居1、中央巡逻1、农田3、谷仓4、农庄护卫4。
- 猎人30%加1只；主桥北侧20%加1只，因此普通敌人为19～21只，另加既有Boss罐头监工·铁腮。
- 普通敌猫使用拾荒田园、哨兵英短、突击美短、猎手银渐；前期区域不放重装敌猫。
- 农庄护卫分西外围、东外围和内院组；内院Boss与护卫可互相警戒，外围不同小组不会通过群体通知一次激活全部人。各组仍可自己发现玩家进入战斗。
- Boss及护卫的移动目标限制在农庄附近，不追到出生区。Boss原有数值和技能不变。
- 地图一使用40单位导航格，其他地图保留80单位格。移动路线检查包含水域和桥梁；子弹遮挡仍按原有战斗墙体规则。

## 模型、授权与可维护性

使用同一作者同一系列：[KayKit Medieval Hexagon Pack 1.0](https://github.com/KayKit-Game-Assets/KayKit-Medieval-Hexagon-Pack-1.0)，CC0。没有购买前提。来源提交、原授权全文、筛选比较和重建命令见 [模型记录](../src/assets/village/README.md)。

六座主要建筑都导入完整模型，经Blender修改颜色、比例、标记和门洞，保留源模型木梁、屋顶、烟囱、门窗或摊棚等结构。未用城堡、兵营和城市素材冒充乡村。将实体内部挖空、屋顶单独拆出，进屋或在建筑后方时按遮挡关系淡化；碰撞采用门洞墙段，谷仓另有侧门。

源包桥梁与围栏按六边形方向制作，导出时校正长轴；桥面统一木色，围栏打通面板并按区域降低高度。统一烘焙顶点色、粗糙材质与现有暖色光照，GLB随站点打包，无远程贴图请求。主要部件按屋顶/主体合并，减少渲染批次。

配置入口：`src/village.ts`（区域、桥梁、道路、碰撞、掉落和刷怪），`src/village-ground.ts`（地形），`src/village-scene.ts`（公开模型与遮挡）。

## 本轮针对性验证

- 6项地图单元测试：河流阻隔与多桥连通；道路中心线不被碰撞阻断；24个种子的全部容器可接近与敌人合法落点；200个种子的区域收益梯度与诊所限制；AI实际过桥与侧门路径；Boss警戒分组、追击范围和地图二至四布局保留。
- 既有四张地图首领/容器可达性用例。
- Chrome实际验证：素材载入无报错、三座桥键盘通行、非桥水域受阻、诊所进屋与双栏搜索、三秒撤离及返回基地；另验证建筑淡化、33度投影和实际受弹不中断搜索。截图保存在本地测试产物中。
