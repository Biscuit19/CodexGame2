# 地图一：猫尾乡野

本轮仅重建地图一。地图二至四、玩家猫咪、装备、物品、搜索速度、15分钟局时、死亡模式及3秒撤离规则沿用现有实现。

宽650的河流从西北进入，经猎人和中央之间，转向下半部向东流出。西支流隔开出生岸与猎人区域。水面实际阻挡移动；AI必须绕桥。桥栏有独立碰撞，桥面顶点与角色脚底统一为高度0，保留下方桥梁厚度，不再以模型外包围盒整体抬高桥面。

三条路线都不强制击杀Boss：

- 安全路线：出生 → 猎人小屋 → 连接桥 → 中央 → A。
- 搜索路线：出生 → 主木桥 → 杂货铺 → 诊所 → 谷仓 → A。
- 高风险路线：中央 → 谷仓 → 农庄 → B（若本局关闭，可退向A或付费点）。

## 容器与资源梯度

| 区域 | 固定容器 | 概率容器 |
|---|---|---|
| 出生 | 纸箱1、猫砂桶1 | 无 |
| 猎人 | 纸箱2、猫砂桶1、工具柜2 | 武器箱50% |
| 中央野外 | 纸箱4、猫砂桶1 | 工具柜40% |
| 诊所 | 医疗箱3、纸箱1、工具柜1 | 豪华猫窝25% |
| 商店 | 纸箱3、猫砂桶2、工具柜1 | 豪华猫窝20% |
| 民居 | 纸箱2、猫砂桶1 | 工具柜20% |
| 农田 | 纸箱3、猫砂桶2 | 工具柜40% |
| 谷仓 | 工具柜2、武器箱1、纸箱2、豪华猫窝1 | 第二武器箱60%、保险箱35% |
| 农庄 | 武器箱2、工具柜2、豪华猫窝1、保险箱1、纸箱1 | 第二豪华猫窝50% |

每个普通容器2件物品，高价值容器3件。容器外形区分纸箱、猫砂桶、抽屉工具柜、医疗箱、长武器箱、软猫窝和带转轮保险箱。

收藏品质权重按区域逐级提高。出生只产常见收藏；野外没有稀世/传说；农田、商店、猎人与诊所可极少出现稀世。传说仅在谷仓（每次收藏抽取0.01%）与农庄（0.1%）出现。此概率不等于每箱概率，因为容器也会抽到装备、弹药和补给。

诊所只抽补给与收藏，不抽枪械、弹药、护甲。猎人更常出现低级弹药，概率武器箱提供1～2级武器。谷仓可出1～3级武器/弹药，农庄可出1～4级武器、2～4级弹药与较高护甲。所有最终搜索位置都经过碰撞校正，容器不会放到水中或墙内。

## 敌人与导航

- 固定19只普通敌猫：猎人2、诊所2、商店2、民居1、中央巡逻1、农田3、谷仓4、农庄护卫4。
- 猎人30%加1只；主桥北侧20%加1只，因此普通敌人为19～21只，另加既有Boss罐头监工·铁腮。
- 普通敌猫使用拾荒田园、哨兵英短、突击美短、猎手银渐；前期区域不放重装敌猫。
- 农庄护卫分西外围、东外围和内院组；内院Boss与护卫可互相警戒，外围不同小组不会通过群体通知一次激活全部人。各组仍可自己发现玩家进入战斗。
- Boss及护卫的移动目标限制在农庄附近，不追到出生区。Boss原有数值和技能不变。
- 地图一使用80单位缓存导航格与A*寻路，其他地图沿用原有寻路。移动路线检查包含水域和桥梁；子弹遮挡仍按原有战斗墙体规则。

## 模型、授权与可维护性

主要建筑、树和木栏改用 [Tiny Treats Homely House 1.0](https://github.com/TinyTreats-Game-Assets/Tiny-Treats-Homely-House-1.0)，CC0。以其原始完整模型为基础，保留圆润屋顶、窗框、门板、檐口和渐变贴图；配色降低饱和度，去掉玩具爱心装饰。诊所加医疗标记，商店增加遮雨棚，谷仓和农庄加猫爪标记与木梁。小型石头、风车、木材和农具保留既有KayKit CC0来源。完整授权、固定提交和重建命令见 [模型记录](../src/assets/village/README.md)。

Blender挖出实际内部空间、拆分屋顶、制作双开门和齐平门槛。进入房间后主体不透明度1%、屋顶0.8%，木地板保持不透明；外部遮挡玩家时也淡化。各建筑采用独立旋转门洞与碰撞，容器按同一变换布置。室内搜索点之间至少150单位，不被旋转后的墙体封住。

保留原始UV、平滑法线和渐变纹理，按相同材质与屋顶/主体/地板合并渲染批次。GLB包含贴图，无远程素材请求。地面纹理限制在4096×3151，避免按世界尺寸创建超大纹理；阴影区域随玩家移动，不把整张地图挤进一张阴影图。

## 大地图与小地图

共享同一张1560×1200绘制地图，按照参考图位置画出河流、道路、桥梁、农田、建筑、树木、围栏和中文地名，另叠加撤离点、Boss和玩家标记。M打开全图；小地图跟随玩家，仅显示附近2600×2000左右范围。地图只用于导航展示，不充当地面贴图。

大地图使用直接挂在body下的原生dialog，以showModal进入浏览器顶层，避免Chrome画布遮挡；M、Esc和关闭按钮均可关闭。

配置入口：`src/village.ts`（区域、桥梁、道路、碰撞、掉落和刷怪），`src/navigation.ts`（大图A*），`src/village-ground.ts`（地形），`src/village-scene.ts`（模型和遮挡），`src/village-map.ts`（共享地图绘制）。
