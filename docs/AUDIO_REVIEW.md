# 四套独立音效试听（等待用户选择）

试听地址：https://biscuit19.github.io/CodexGame2/audio-review/

本轮只修复出战检查残留弹窗，并添加独立试听页。**没有把四套候选中的任一套接入游戏，没有更换现有游戏音频，也没有改动游戏音量设置或存档。** 用户已否决上一轮Warfork为主的粗糙、大音量方案，后续必须等待明确选择再接入。用户所说的装备声指从容器穿戴／装备进入装备栏，不能再把它用于局内切枪；切枪恢复原先安静的行为。

## 音量与处理

- 四套采用同类活动区间RMS参考值及峰值上限，而非把每个样本都拉满。枪声目标RMS约0.013、换弹约0.0045、动作约0.0055；峰值上限分别0.075、0.035、0.035，不做失真饱和／硬限幅。
- 采用平滑滤波、短淡入淡出，减少尖锐起音与毛躁高频，保留枪型之间的包络和重量差异。64项MP3的实际解码峰值在约0.0153～0.0713之间，均远低于削波；源音量不等于设备实际响度，主观结果由用户试听确认。
- 枪声、换弹与动作分开参考音量，音效不比大小。连射是额外的预览混音，便于观察持续听感，不宣称等同游戏内所有并发场景。
- 原版参考按旧合成方式和默认主音量/SFX增益渲染；试听音量统一控制这些参考和新方案，默认80%。没有改动游戏音量。
- D用正弦低频包络、木质模态轻敲和少量带通平滑噪声组合；不使用方波、锯齿、数字削波或上一轮的外部枪声。近战与翻滚分开设计。
- 所有描述为设计目标及信号分析结果，未声称完成主观试听评分。

## 复现与验证

```sh
python scripts/assets/build-audio-review.py --cache /tmp/tricat-review-sources
```

需要Python、numpy、scipy、ffmpeg。只生成`public/audio-review`，不触碰游戏的`src/assets/audio`。素材授权文本保留在预览目录。D原创合成的随机种子固定，可复现。试听包内包含许可说明。

测试按改动范围执行：Chrome验证独立页的逐项播放、互斥播放、四套对比顺序、停止、音量、分类、连射、ZIP下载；68项音频真实解码；桌面和手机截图；无游戏存档写入。出战弹窗分别验证缺食物、空装进入战斗后关闭顶层基地弹窗，菜单、背包可实际操作。独立页缓存键与游戏首页分开，避免访问试听页把离线游戏入口替换成试听HTML。
