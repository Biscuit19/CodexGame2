## 界面与资源

- homestead.css 替换旧页面样式，深绿底色延伸至仓库、商店、收藏页面，保留物品品质色。通用局外按钮改为切角式圆角、明确抬升/压下和焦点环。
- 原开始图以CSS缓慢推近、平移，叠加轻微光色变化。纯视觉图层不接收指针，不移动菜单点击区域。
- 基地功能入口使用现有获准物品图集，仓库枪械、商店食物、收藏品；大标题和可见操作优先于装饰图。
- mission-art.ts 是原创区域示意SVG：乡野河桥/农田、高架道路、港口街区、研究站。明确标注非导航地图，不虚构准确路线。虚线流动和标记呼吸表达选图氛围。
- 地图名称、描述、区域、撤离费和首领继续读取实际 maps/bosses；装备建议沿用原1至4级推荐。资源提示仅列实际存在的武器箱、物资与收藏品，不承诺概率或固定掉落。
- 所有新增动画响应 prefers-reduced-motion；地图选择后仍恢复键盘焦点，锁定地图可浏览但出发禁用，沿用出战检查。

不调整平衡、音源、音量、存档、地图生成或原生dialog结构。统一调整台继续读取实际配置。
