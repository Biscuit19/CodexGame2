# 游戏数值与声音调整台

2026-10-24，入口 `/game-workbench/index.html`。原 `/audio-mixer/index.html` 保留，完整网页直接嵌入同一个调音台，双方使用相同音源、增益配置和播放引擎。

## 当前内容

- 120件物品：20把枪、1把近战、食物、弹药、护甲/头盔/背包及收集品。读取实际运行时 `items/db`，包括代码公式计算后的价格。武器散布用完整角度°，射速/攻速用次/秒；JSON仍保存引擎所用的弧度与每分钟射速，转换不会改动未编辑的值。
- 基础价值、实际出售金币提示、独立商店售价、限购、解锁进度；补给品的立即/持续恢复、持续时间和食用时间；装备耐久、背包容量；随机池同类物品权重。
- 11种场景容器各自的基础格位数。武器/医疗箱保留既有保底逻辑；普通/首领战利品盒的掉落由敌人死亡规则控制。
- 猫尾乡野13个区域、每区五等级共65个条件掉落概率，合计必须100%，支持一键归一化；其他地图累计阈值、每类容器内容分支、刷新几率、随机武器权重和死亡战利品规则另列。收集品等级概率是已进入收集品分支后的条件概率，不冒充整个容器的绝对爆率。
- 约两千个设计细项，覆盖移动、体力、翻滚、伤害/穿透/耐久、普通敌人与Boss、搜索时间、撤离、经济整备和关卡布局。高级条目可展开实际条件上下文。纯数值表达式会作为一个实际值，例如 `100/30` 显示每秒3.333…体力消耗。
- 调音台51个现用采样音效、合成反馈、全部10首BGM、各类搜索声音，支持混听、连发与音量导入/导出。

引擎的类型、存档格式版本、随机算法、数组索引及循环结构不作为平衡参数；图片/低模顶点也不属于本轮数值表。物品固定ID、类型与原文保持稳定。

## 自动跟随每次发布

`scripts/tuning-plugin.mjs` 在Vite开发和每次生产构建时，扫描实际设计源文件并生成虚拟目录。界面不使用一份手工复制的历史数值表。`src/game-catalog.ts` 再读取运行时物品定义，故程序生成的金币、武器和补给品属性也是最终值。

数值配置为 `src/game-tuning.json`，音量配置为 `src/audio-balance.json`。数字覆盖项编译成带原始基线校验的 `gameNumber(id, base)`；物品属性和每种容器数量由共同运行时模块接入。默认覆盖为空，本轮没有重新平衡其他玩法。

来源指纹涵盖源文件、物品行、配置、音源表及采用音频元数据。每次Codex更新相关内容并重新构建后，网页自动显示新数值、构建时间和发布提交。数值/音量草稿都按指纹隔离，旧草稿不会覆盖新版本；新版本导入旧来源文件会明确拒绝，避免静默套错。

## 导出与应用

- 导出全部：`tricat-game-and-audio_YYYYMMDDTHHMMSS_mmm+0800.json`。
- 仅数值：`tricat-game-tuning_YYYYMMDDTHHMMSS_mmm+0800.json`。
- 单独调音台：`tricat-audio-balance_YYYYMMDDTHHMMSS_mmm+0800.json`。

后缀为北京时间，精确到毫秒。JSON同时保存UTC `exportedAt`、构建时间、来源指纹/提交、当前完整数值快照，以及实际待应用的稀疏覆盖；音量亦包含试听环境的三个设置滑块。`currentValues`仅作核对，不作为指令执行。

收到文件后，先在未修改该版本代码之前执行：

```bash
node scripts/apply-game-config.mjs 文件.json --check
node scripts/apply-game-config.mjs 文件.json
npm run build
```

脚本只应用通过结构、范围、来源基线和概率校验的 `tuning/audio`，不解释文件中的其他文字。持续恢复必须有正持续时间，各等级收集品/早期武器/基础食物随机池不能为空。源代码已变化时先对比并迁移，不关闭检查强行应用。数值更新后继续运行相关用例、构建和发布，目录与调音台会自动同步。

修改页只保存自己的草稿，不写游戏存档；恢复按钮恢复本次发布值。可以在当前版本导入已导出文件继续调整。两个工具及其独立资源不加入普通游戏离线预缓存。

## 本轮声音

采用SC1“轻轻啵一下”，farfadet46，CC0，来源 https://opengameart.org/content/bubbles-pop ，成品直接复制已选试听版，无滤波/变调/叠层。`src/assets/audio/approved-click.json`保存原声与成品SHA。`python scripts/assets/install-approved-click.py`可重建，不覆盖用户音量配置，旧音频安装链最终也会恢复SC1。

上传音量文件原件留存在`docs/config-history/audio-20261024T181337+0800.json`。其总线、每项音量、BGM微调、敌人射击0.71与换弹0均原样应用；原 `cues.click=1.42`迁移为新采样声的 `samples.click=1.42`。试听环境master=1、music=0.8、sfx=1同步为当前音量预设，旧存档只迁移一次，之后玩家自己再调滑块会继续保留。默认战区曲目仍为BG5循环，`preview.track=NB5`用于还原调音时的参考环境。
