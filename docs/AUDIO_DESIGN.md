# 游戏当前音效接入

枪声与换弹已采用用户从试听页选定的真实录音，精确来源、裁剪、拼接、音量和本轮两段高频柔化见 [AUDIO_SELECTED.md](AUDIO_SELECTED.md)。之前被否决的 Warfork 枪声混音不再用于枪械，也不再由当前构建入口生成。

| 用途 | 当前来源 | 制作 / 运行规则 |
|---|---|---|
| 冲锋枪单发 | SnakeF8 E 9mm | 保留完整单发，统一音量 |
| 步枪单发 | SnakeF8 E 7.62×54R | 高频轻微柔化，统一音量 |
| 狙击单发 | Mike Koenig G .416 | 最后一次击发直至结尾，保留弹壳尾声 |
| 霰弹单发 | Mike Koenig G 10 Gauge | 高频轻微柔化，统一音量 |
| 冲锋枪 / 步枪换弹 | SnakeF8 E AR 完整换弹 | 同一原音；按每把枪实际换弹时间匹配播放速率 |
| 狙击换弹 | SnakeF8 E .308 完整换弹 | **已移除末尾 H Mossberg 声**；按实际换弹时间同步 |
| 霰弹换弹 | Mike Koenig G 换弹前1.8s → SnakeF8 E 泵动换弹 | 先匹配两段响度，再依次拼接；按实际换弹时间同步 |
| 敌人射击 / 换弹 | 与玩家同类相同源 | 增益为玩家75%，不改变音高 |
| 装备武器、护具、翻滚、挥刀 | 保留当前四个 OGG | 本轮未更换或重新生成；来源与哈希见 [foley-sources.json](../src/assets/audio/foley-sources.json) |
| 局内切枪 | 恢复原来的安静行为 | 不再调用较大音量的“从容器装备武器”声音；仍取消未完成换弹 |

八个枪械成品使用无损 FLAC，游戏解码与试听 WAV 的采样完全一致。四个动作 OGG 保持原始字节不变；音乐、搜索、受伤、提示等沿用已有实现，未调整全局音量或存档设置。样本预加载、解码缓存、换弹取消、过期射击丢弃及40声部上限继续保留。

## 授权

当前枪械包含 **CC0 和 CC BY 3.0**，不能再统一标为 CC0。游戏设置中的“音效来源与许可”链接到 [公开署名页](../public/audio-credits.html)，包含 SnakeF8、Mike Koenig、原录音标题与链接、许可及修改说明。四个保留动作的旧来源为 Warfork 的 CC0部分、Kenney RPG/Impact、Ben Burnes Organic Wooshes，原许可文本仍保留在 [licenses](../src/assets/audio/licenses)。

[来源比较与备选](AUDIO_REVIEW.md)记录此前实际检索的多个网站、作者、下载量、评分及许可限制；本轮严格采用用户已选的音源，不另外更换素材。

## 构建和相关验证

```sh
python scripts/assets/build-game-audio.py
```

入口调用已批准枪声生成器，读取固定原素材、验证哈希、生成同源试听和游戏文件，保留动作只校验。原先被否决的武器合成逻辑仅留在 Git 历史，不会被现用脚本误覆盖回来。

相关检查覆盖当前12个样本实际解码、真实四类射击及换弹时间、敌人75%增益、切枪取消换弹和静音、装备动作仍走原逻辑、同源试听连发与下载；不每轮重复其他地图、战斗全量或跨浏览器全套测试。
