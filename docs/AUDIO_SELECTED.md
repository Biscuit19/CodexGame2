# 已接入游戏的枪声与换弹

当前同源试听：https://biscuit19.github.io/CodexGame2/audio-review/selected/index.html

按 2026-10-21 用户最新要求，**四类枪声与换弹现已接入游戏**。翻滚、装备武器、装备护具和挥刀四个已有录音文件未更换。切枪恢复原先安静行为，不再误播从容器装备武器的较大音效；真正装备进入栏位仍使用原有装备声。

## 当前采用

| 枪型 | 单发录音 | 换弹录音 |
|---|---|---|
| 冲锋枪 | E `9mm 单发｜轻型枪声候选` | E `AR 完整换弹` |
| 步枪 | E `7.62×54R 单发｜栓动步枪`；轻微柔化刺耳高频 | E `AR 完整换弹`，与冲锋枪一致 |
| 狙击枪 | G `.416 Barrett 狙击枪｜三次射击`，从约 2.03s 起截取第三次击发至原文件结尾，保留击发前约 20ms 间隙及全部弹壳尾声 | **只保留 E `.308 栓动完整换弹`**，原长约 2.0625s；末尾 H Mossberg 声已取消 |
| 霰弹枪 | G `10 Gauge 霰弹枪｜立体声`；轻微柔化高频毛躁感 | G `退出弹匣并换弹`精确前 1.8s → E `泵动霰弹枪完整换弹`，按顺序拼接 |

所有连发仍逐次播放所选的**同一个单发**，不用原素材的连发录音替代。狙击枪单发尾声与霰弹枪换弹拼接规则保持上轮选择。

## 本轮柔化范围

只对用户指定的两段枪声做轻量高频搁架衰减：

| 声音 | 处理 | 校验 |
|---|---|---|
| 步枪 | `highshelf=f=4200:g=-3:t=q:w=0.707` | 相比上轮，8–16kHz 对 0.2–1.8kHz 的相对能量约降低 2.81dB；时长不变 |
| 霰弹枪 | `highshelf=f=3500:g=-3.5:t=q:w=0.707` | 同一相对能量指标约降低 2.91dB；时长不变 |

这是针对“刺耳、毛躁”的轻微柔化，不重做枪声、不改变音调或节奏。其他枪声与换弹不加滤波；没有增加压缩器、限幅器、混响、淡化或合成层。频段指标是客观处理校验，不代替用户对主观听感的判断。

## 音量、格式与同步

- 霰弹枪换弹的两段先各用固定线性增益匹配至 −28.3 LUFS，再顺序拼接；没有重叠、交叉淡化或人工插入间隔。
- 对八条成品重新统一固定增益：综合响度均为 **−28.4 LUFS**（EBU R128 分析精度 0.1 LU），真峰值不高于 **−1dBTP**。目标由保留自然动态且不削波所需余量决定，不用压缩器强行拉响。
- 试听输出 24-bit PCM WAV，游戏以**无损 FLAC**打包。逐文件解码比较完全一致，不再次经过 Vorbis/MP3 有损压缩。
- 采样率 44.1kHz、立体声。本轮已不使用 48kHz 的 H 段，不再需要其采样率转换。
- 试听播放器默认 100%。游戏沿用主音量和音效设置，不擅自修改存档音量；敌人枪声与换弹使用相同音源，增益恰为玩家的 **75%**。
- 游戏换弹使用 `录音时长 / 武器实际换弹秒数` 同步播放速率。比如当前约 2.0625s 的 .308 换弹可适配 2.4/2.8/3s 的武器。切枪、换弹取消和退出本局保留原中断逻辑。
- 只保留已有 40 个声部上限和样本预载逻辑，不改战斗数值、敌人 AI 或地图。

## 试听页连发

可选枪型、30–1200 发/分和 3/5/10/20 发。默认值为冲锋枪 720、步枪 600、狙击枪 45、霰弹枪 70 发/分。

按 `60/RPM` 的间隔叠放完整单发，保留每一发尾音。若叠加峰值过高，只对该整段试听连发采用一个固定衰减，不逐帧改变音量，不是压缩/限幅效果。游戏播放仍由真实射击事件逐次触发，受游戏音量设置控制。

## 复现和验证

```sh
python scripts/assets/build-game-audio.py
# 等价：
python scripts/assets/build-selected-audio.py --install-game
```

仅依赖 Python 与 ffmpeg/ffprobe，读取仓库中的固定原素材。构建脚本验证源 SHA-256，再裁剪、柔化指定两条、匹配拼接与统一响度，输出试听 WAV 和游戏 FLAC，并断言两者解码完全一致。

- [试听清单](../public/audio-review/selected/manifest-v2.json)：每条的源、剪切、固定增益、EQ、LUFS、真峰值和成品 SHA-256。
- [游戏源索引](../src/assets/audio/sources.json)：游戏 FLAC、对应试听 WAV 哈希和保留动作索引。
- [选材比较](AUDIO_REVIEW.md)：保留之前按不同作者检索、比较及核验授权的记录。本轮直接采用用户已选择的原音，不重新另选作者替换。

只运行相关单元用例、Chrome 的真实四枪型射击/换弹/敌人减音/切枪取消/解码，以及受影响的同源试听页测试。另以解码和频段测量核查无损一致性、响度、柔化幅度及 .308 换弹长度，不执行战斗或地图全量回归。
