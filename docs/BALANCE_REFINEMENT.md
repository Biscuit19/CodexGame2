# 2026-10-31 音乐、配装与战斗手感调整

本轮覆盖此前《COMBAT_PRESSURE_ECONOMY_MUSIC》中的移速、减伤、环射和默认音乐方式。地图布局、容器和经济价格未改。真实数值由统一调整台自动读取源码，子弹表现也纳入目录。

## 音乐与整备

- 基地和战区默认随机，从进入该场景的**第一首**开始随机；后续切曲排除刚播放曲目。两个曲库相互独立。旧存档一次迁移为随机，此后保留用户自己的循环/随机选择。预览调音台仍直接播放指定曲目。
- 仓库扩容使用原生顶层确认框，显示费用、原格数、目标格数；确认才扣钱，取消、Esc、关闭均不扣钱。金币不足时确认禁用。
- 仓库“一键配装”：在玩家现有仓库、背包及装备中选最低等级、最低价格的可用枪、头盔、护甲、背包、刀和食物，有第二把枪则补副武器，补够120发携带弹药。坏掉的装备排除，背包须装得下现有物品。高等级旧装备放回仓库，不购买、不销毁、不凭空补物资；缺物资明确提示。若整理后容量仍不够，整次操作不提交。
- 自动补食物仅在当前食物用完/空缺时发生：生命低于50选最高等级，再按价格；否则选最低等级。已装备食物不强行替换。

## 伤害与护具

普通敌人不再有12/20的固定最低武器伤害。普通射击/普通技能基础伤害为实际枪械伤害×0.62×武器耐久倍率，瞄准技能×0.72；Boss按实际武器×0.9。仍使用枪械散布、射程、多弹丸与衰减，连发射速和快弹速保留。

最终伤害 = 基础伤害 × 弹药倍率 × 护具穿透系数 × 命中部位倍率 × 距离倍率，单颗命中最低1点。弹药倍率仍为0.75/0.88/1/1.15，穿透等级仍为1/2/3/5。

| 护具等级 − 弹药穿透等级 | 满耐久时保留的伤害比例 |
| --- | --- |
| ≥3 | 5.5% |
| 2 | 10% |
| 1 | 22% |
| 0 | 55% |
| −1 | 82% |
| ≤−2 | 95% |

护具耐久比例c按实际头盔/护甲各自满耐久计算，实际系数=1−(1−满耐久系数)×√c。无甲/碎甲系数为1，耐久逐渐降低时防护逐渐失效。头部仍为1.2倍，翻滚减伤仍保留。玩家护具磨损按实际伤害×0.3、每次最低0.15计算，避免低级弹迅速磨穿高级甲。

例：武器基础22.4的普通敌人，一级弹对满三级甲造成约1.04点；三级弹则约7.64点。不同枪械和弹丸数量仍有差别，不把所有枪硬设为同一伤害。此穿透计算同时作用于敌人护具，低级弹对Boss三级甲仍需磨损。

## 爆头与战斗移动

- 敌人射击以身体为主。普通敌人每次开火仅3%（三级以上6%）、Boss8%明确尝试瞄头；这只是瞄准意图，**不保证爆头**。
- 敌弹还必须真的穿过头部、原瞄头位置仍在玩家当前头部范围内，才按头盔处理；普通身体弹即使在2.5D轮廓中先碰到头顶也只算身体伤害。移动离开原瞄头点可以使爆头失效。玩家原有准星瞄头与侧面/下方弹道处理保留。
- 普通敌人每只固定分配0.72/0.85/0.95/1.2的移速系数，三个较慢档、一档较快，出生后不每帧随机变速。原普通战斗全员1.25、追击1.65加速改为1/1.1；短冲刺/闪避仍只由特定战术触发。
- 战斗状态头部朝玩家；包括调查结束进入战斗、失去射击条件但追击以及技能过程，不再沿用旧巡逻朝向。绕行、后撤等动作仍可存在。
- 铁腮保持三头三甲三弹、850生命、无阶段。基础战斗移速110、技能间隔2.8秒，接近后可侧移；保留滚动后连喷、跟踪连发、推进射击、交替瞄准射击，用朝目标方向的11弹丸双喷替代360度环射。跟踪/推进等快速攻击也一次3弹丸。普通技能没有新增地面预警。
