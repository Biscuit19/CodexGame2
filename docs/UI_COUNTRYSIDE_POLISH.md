## 界面实现

- `src/ui-theme.css`统一主题：奶油色自然背景、深鼠尾草绿面板、暖金主行动按钮、细金属色边线、内侧高光、柔和阴影与统一圆角。
- 开始页加入象征乡野丘陵的轻背景和奶油卡片。基地入口增加细线装饰、图标托底、悬浮抬升与图标轻摆；概览卡使用明亮纸面层次。
- 仓库、商店、收藏、地图选择、设置、菜单、确认框、物品菜单与结算共用材质/边框层次。稀有度原色和功能文字色保留在深色物品卡上；奶油背景的标题改用深墨绿保证对比度。
- 物品格悬浮仅让内部图标轻抬，避免改变格子/拖拽布局。按钮有按压反馈、禁用状态与键盘焦点；支持 `prefers-reduced-motion`。
- 弹窗继续挂在 body 下使用原生 dialog，不添加嵌套 fixed/背景模糊组合。
- 战斗生命、体力、装备耐久分层：生命主读数、独立细体力条、头盔/护甲图标与耐久短条。食物显示名称、份数、Q键和真实即时/持续恢复量，直接读取现有 `foodEffect`。
- 左下和武器栏采用自适应布局，1100宽窗口依然完整。武器图标以实际容器宽度计算，保持原图比例。

## 追加平衡要求

- 普通敌弹（含特殊攻击）实际速度整体×0.7：950→665，特殊1100→770；玩家弹1050和Boss弹1100保持。走位预判按新的普通弹速计算，碰撞步进规则不变。
- 地图1普通收集品分布提高蓝色机会：例如野外23%蓝/2%紫、农田27%蓝/3%紫、民居25%蓝/3%紫，均为**收集品分支的条件概率**，不是每个容器必出。
- 保险箱/猫窝至少第一件为蓝或以上收集品；武器箱如整箱没有蓝或以上，会用最后一格补入蓝或以上收集品，保留原枪械/弹药功能。单格武器箱则保底蓝枪。其他地图高价值容器也补蓝保底。空的禁用容器不强行生成物资。
- Boss外围分布2%白/15%绿/50%蓝/31%紫/2%传说，核心0%白/5%绿/43%蓝/48.5%紫/3.5%传说。高价值容器的保底项会在蓝及以上权重中重新归一化，其他格仍按区域分布。
- 安全箱/猫窝仅收集品规则保留，不塞高级子弹。房屋、资源点位置与容器数量不变。随机内容基线按获授权掉落调整更新。
- 数值调整台由实际源码重新生成，非另一份手填历史表。
