# 开始页与基地：完整重设计

## 实施前的设计提示词

为《三角猫行动》重新设计游戏封面与暖窝基地。采用“黄昏乡野探险画册 × 精装旅行装备箱”的视觉方向，保持卡通猫咪世界的温暖感。使用深墨青、象牙白、香槟铜金与夕阳杏橙；文字必须高对比、大字号、明确层次。不要沿用旧的居中菜单和等大磁贴网格。

开始页使用非对称全屏构图：左侧超大中文标题、独立纵向导航；右侧以原创分层乡村插画建立空间感，包含远山、河流、暖灯小屋、木桥与猫咪旅人。金属徽章、细线边框、纸张纹理、柔和投影和局部暖光形成材质层次。不要用低对比文字叠在繁杂背景上。

基地改成有明确操作顺序的整备大厅：顶部身份与金币；左侧场景主视觉和行动统计；右侧突出的“仓库配装”，其后为商店、图鉴；底部清晰的出发按钮。出发后才选择地图，保留现有模式/存档规则，不增加另一套难度设置。去掉单独的战区地图功能入口。仓库也提供出发入口。

动效要有层次：页面元素依次进入、云层轻移、暖灯呼吸、微小光粒漂浮；按钮悬浮产生光泽移动、图标转动与箭头位移，按压有清晰回弹。背景动效不能影响文字、点击位置或帧率。键盘焦点与鼠标悬浮同样清晰，尊重减少动态效果设置。小屏改成上下结构，不裁切重要操作。

保留所有既有 data-action / 存档 / 配装 / 设置 / 出战检查接口；仅按明确需求改变入口和全部放回的范围。

## 参考与取舍

- [Awwwards 游戏网站设计集合](https://www.awwwards.com/websites/games/)：查询封面式大画幅、强字体层级和非网格导航的参考。集合页可访问，不把未逐一打开的项目当作已体验案例。
- [Motion hover animation](https://motion.dev/docs/react-hover-animation)：查阅悬浮、离开时的动画回退与手势处理方式。项目本身为原生 DOM，使用 CSS 实现相同交互思路，不引入 React 或动效依赖。
- 场景为本项目原创 SVG，未复制参考网站图像；所有资源随构建本地打包。

## 功能同步

- “仓库配装” → “准备出发” → 选择地图 → 原有出战前检查 → 战区。
- 全部放回包含背包与安全箱；仓库不足时未转移物品留在原处，装备不卸下。
- Boss 攻击计时倍率 1.2：普通射击、技能间隔和射击连招计时加速；翻滚距离、移动速度、子弹速度、伤害与普通敌人不变。实际遭遇频率仍受视线和换弹限制。
- 数值调整台直接由运行时代码生成，包含本轮 Boss 倍率。

## 验证

- 真实 Google Chrome：新游戏、继续游戏、设置、临时测试入口、基地悬浮与键盘焦点、仓库仅安全箱有物品时全部放回、出发选图、出战检查与进入战斗；1100/640 宽度与减少动态效果。截图逐张检查主页面、创建页、设置和窄屏。
- 单元测试：仓库空间不足时安全箱物品完整保留；Boss 连招间隔约缩为 1/1.2，普通敌人不加速；原有十一招、翻滚碰撞、数值调整台相关检查。
- 既有测试中的旧入口名称同步为“仓库配装 / 准备出发”，没有因更名执行无关全量测试。
